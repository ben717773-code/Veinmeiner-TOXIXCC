# HammerVein
Paper-Plugin (1.21.11, Java 21): Veinminer (Shift) + 3x3-Spitzhacke.

## JAR bauen
Variante A (lokal): JDK 21 + Gradle installieren, dann `gradle build`.
JAR: build/libs/HammerVein-1.0.0.jar

Variante B (ohne Installation): Ordner als GitHub-Repo hochladen,
Tab "Actions" -> "Build" laeuft automatisch -> JAR unter "Artifacts" laden.

## Modrinth
Projekttyp: Plugin | Loader: Paper | Spielversion: 1.21.11 | Datei: die JAR
